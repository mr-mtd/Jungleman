# Jungleman

A 2D jungle action-platformer for **Godot 4.3+**, inspired by *Pitfall: The Mayan Adventure* (1994).
All art is original, generated by `tools/generate_art.py` in a smooth, high-resolution cartoon style
(soft gradients, rim light, layered parallax jungle, drifting leaves and fireflies).

## Running

1. Open Godot 4.3 (or newer) and import `project.godot`.
2. Press **F5**. The game starts in Level 1, *The Mayan Jungle*.

## Controls

| Action | Keyboard | Gamepad |
| --- | --- | --- |
| Move | Arrow keys / A, D | D-pad / left stick |
| Crouch / climb down a vine | Down / S | D-pad down |
| Climb up a vine | Up / W | D-pad up |
| Jump / let go of a vine or zipline | Space / Z | A |
| Crack the whip | X / J | X |
| Throw a sling stone | C / K | B |
| Pause | Esc / Enter | Start |

Hold Jump for a higher jump; tap it for a short hop.

## What's in Level 1

- **Pitfalls**: bottomless gaps you have to jump.
- **Tar pits**: you sink slowly and can barely move. Mash Jump to climb out before you go under.
- **Swinging vines**: jump into one to grab it. Push in the direction of the swing to pump it higher, climb up or down to change your reach, and press Jump to let go with the vine's momentum.
- **Crocodile pond**: the water is deadly. Hop across on the crocodiles' backs, but stay off the snout when their jaws snap open.
- **Crumbling rope bridge**: the planks give way shortly after you step on them, so keep running.
- **Zipline**: climb the temple tower, jump up to the rope and ride it across the chasm.
- **Rolling logs**: jump over them.
- **Enemies**: snakes that lunge when you get close, patrolling scorpions and swooping bats. Whip them or knock them out with sling stones.
- **Pickups**: gold treasure, sling stone bags, canteens (restore health) and a golden statuette (extra life).
- **Checkpoint idols**: touch a stone idol to turn it gold; you respawn there after losing a life.
- **Temple exit**: walk into the temple doorway to finish the level.

You have 3 lives and a health meter. Running out of lives shows Game Over; press Jump to restart.

## Project layout

```
assets/          generated sprite sheets, SpriteFrames (.tres), tiles and parallax backgrounds
levels/          level maps (ASCII, one character per 16x16 tile)
scenes/          player, entities, HUD and level scenes
scripts/         GDScript: player.gd, level.gd, entities/, ui/, autoload/game_state.gd
tools/           generate_art.py (regenerates all art; needs Python 3 + Pillow)
```

### Editing the level

`levels/level_1_map.gd` holds the map as rows of text. `scripts/level.gd` turns it into tiles,
hazards and enemies at runtime; its header lists every map character (`#` ground, `T` tar,
`V` vine, `C` crocodile, `B` bridge plank, `Z`/`z` zipline ends, and so on). Edit the rows and
press F5 to try your change.

### Changing the art

Art is stored at 4 texture pixels per world pixel and scaled down in game, so it stays crisp up to
1080p while gameplay sizes stay the same. The game renders with the `canvas_items` stretch mode and
linear filtering for a smooth, non-pixelated look.

Each animation lives in a sprite sheet with a matching SpriteFrames resource (for example
`assets/sprites/player.png` and `player_frames.tres`), so you can swap in hand-drawn art in the
editor's SpriteFrames panel. If you replace a sheet, keep the 4x scale or adjust the sprite's `scale`.

Terrain is painted by `scripts/ground_art.gd` from `assets/tiles/` (seamless soil, grass edge, stone,
ledge); the TileMapLayer is kept hidden and only provides collision. Tar and water are drawn in code.

To tweak the generated art, edit `tools/generate_art.py` and run `python3 tools/generate_art.py`
(needs Python 3 with Pillow and NumPy).
